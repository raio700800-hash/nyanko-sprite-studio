# Nyanko Sprite Studio

**完成済みの「3面図 Master画像」からキャラクターを固定したまま、アニメーション用の透過スプライトシート＆透過アニメーションGIFを生成・テスト再生・Antigravity 2.0 へそのまま組み込みできるローカル制作スタジオ**です。

MacBook Pro 上で制作中の「にゃんこ探しゲーム（15匹の猫が登場する脱出ゲーム）」向けに設計されています。

---

## 主な機能

1. **3面図 Master によるキャラ固定**
   - 別アプリで作成した正面・横・背面の3面図画像をドラッグ＆ドロップで登録。
   - 「模様・首輪・目色・主線」の特徴メモを併用し、単なる3面図切り貼りではない全身アニメーションを生成します。
   - **15匹のにゃんこ管理ロスター**（ブラウザ IndexedDB に自動保存）で、15匹＋αのキャラクター・部屋背景スクショ・生成履歴をまとめて管理できます。

2. **モーション＆画風変換プリセット ＋ 日本語演出プロンプト**
   - プリセット：`歩き` / `走り` / `待機` / `怒り` / `喜び` / `驚き` / `お座り` / `寝る` / `チラ見` / `自由演出`
   - 向き：`右向き` / `左向き` / `正面` / `背面`
   - 画風変換：`元の画風を厳密維持` / `ドット絵 (16-bit)` / `2Dアニメ` / `ちびキャラ` / `絵本・水彩`
   - 自由入力の日本語プロンプト窓 ＋ 「英語に最適化」ボタン（APIまたはオフライン簡易辞書）

3. **コマ数（4〜16枚）・アスペクト比・出力サイズ設定**
   - スライダー＆ボタンで **4〜16コマ** を選択可能（例：8コマなら自動で `4×2`、12コマなら `4×3` / `6×2` などを最適算出）。
   - 1コマのアスペクト比：`1:1`, `4:3`, `3:4`, `16:9`, `9:16`, `カスタム`
   - 1コマのサイズ：`64px`, `128px`, `256px`, `384px`, `512px`, `自由(px)`

4. **低コストAPI生成 ＆ 完全0円手動連携の両対応**
   - **格安API自動生成**：OpenRouter (`FLUX 3 Image Klein` 約1.4円/枚, `GPT Image 1 Mini`, `Nano Banana 2 Lite` 約5円/枚, `Seedream 4.5` 等) / Gemini Direct API / fal.ai に対応。
   - **0円手動連携**：APIキーなしでも「生成用プロンプトをコピー」→ 無料の Gemini Web アプリ等へ 3面図と一緒に貼付 → できた画像をドロップ（または `Cmd+V` / `Ctrl+V`）するだけで全機能が利用できます。

5. **背景透過・足元揃え・プレスト（Presto）実機再生テスト**
   - **外周フラッド背景透過**（白い毛並みや目の中が抜けない安全アルゴリズム）＆ **全体キー**、許容しきい値、Feather、Despill（白フチ除去）、スポイト指定に対応。
   - **足元中央揃え / 重心中央揃え** でコマ間のサイズ・立ち位置ブレを自動補正。
   - **コマ編集タブ**：コマのON/OFF、並べ替え、X/Y 2px単位の位置微調整、画像差し替え、「このコマだけ再生成」。
   - **プレスト再生ステージ**：透過チェッカー / 白 / 黒 / **実ゲーム部屋背景テスト（ドラッグ移動・パトロール歩行・サイズ倍率調整）**、FPS (1〜24)、ループ / 往復 (Ping-Pong) / 1回再生、オニオンスキン、**実GIF確認**。

6. **Antigravity 2.0 連携 全部入りZIP書き出し**
   - `<slug>_<motion>.png`（透過PNGスプライトシート：グリッド配列 / 横1列ストリップ切替可）
   - `<slug>_<motion>.gif`（透過アニメーションGIF：残像防止ディスポーズ対応）
   - `<slug>_<motion>.meta.json`（フレーム座標・FPS・ループ・アンカー情報）
   - `frames/frame_00.png ...`（個別透過PNGフレーム一式）
   - `ANTIGRAVITY_PROMPT.md`（そのまま Antigravity 2.0 に貼り付けてゲームへ組み込めるプロンプト＋React/Canvasコード例）
   - オプションで「左右反転ペア」も一括同梱できます。

## MacBook Pro でのセットアップ・起動手順

必要な環境：Node.js 20 LTS 以上

```bash
# 1. リポジトリを取得して移動
git clone <YOUR_REPO_URL>
cd nyanko-sprite-studio

# 2. パッケージをインストール
npm install

# 3. APIキーを .env で管理したい場合（任意：画面上の「API設定」からも設定可能）
cp .env.example .env

# 4. 開発サーバー起動（フロント Vite + ローカルAPIプロキシを同時起動）
npm run dev
```

ブラウザで `http://localhost:5173` を開くと、最初から **サンプル三毛猫「ミケ」の3面図・8コマ歩行シート・和室背景** が読み込まれた状態で起動します。

### ビルド・本番起動・チェックコマンド

```bash
npm run lint     # Oxlint チェック
npm run build    # TypeScript 型チェック + Vite 本番ビルド
npm run start    # 本番ビルドを単一サーバー (http://127.0.0.1:3001) で起動
```

## APIキーについて（任意）

`.env` に記載するか、アプリ右上の **「API設定」** モーダルに入力します（APIキーはローカルにのみ保存され、Git管理対象外の `.env` またはブラウザの `localStorage` に保持されます）。

- `OPENROUTER_API_KEY`: OpenRouter 経由で `black-forest-labs/flux-3-image-klein`（約1.4円/回）〜 `google/gemini-3.1-flash-image` まで1つのキーで利用可能（試行錯誤に最安）
- `GEMINI_API_KEY`: Google AI Studio キーで `gemini-3.1-flash-image` / `gemini-3.1-flash-lite-image` を直接呼び出し
- `FAL_KEY`: fal.ai キーで `blackforestlabs/flux-3/edit-image` 等を呼び出し
